# 古诗格律校勘台

面向诗词编辑与校勘人员的浏览器工作台。可逐字标注平仄、韵组和停顿，建立对仗关系，记录每条判断依据，并对多个异文版本进行并排定位。

## 功能

- 录入诗句并按五言、七言格律模板逐字对照。
- 平仄、停顿、韵组、判断依据和批注可逐字维护。
- 自动提示出律位置、一三五位置可接受变体、待标字和重复用韵。
- 建立句间对仗关系，记录关系说明。
- 多版本独立校勘：底本与当前稿按字符（最长公共子序列）对齐，**增字、缺字、换字分别归位**，不再因一字增删整段错位。
- 连续变化自动合并为**异文段**，可上一段／下一段或段号逐段跳转，并展示每段两边用字及各自批注、依据。
- 文本增删后，原有平仄、韵组、停顿、判断依据、批注**随原字迁移**，对仗关系随句移动；被删字的批注不串给邻字。
- 旧版浏览器本地记录自动升级（沿用原存储键），升级后仍可打开编辑与导出。
- 文档级撤销/重做、键盘巡校和浏览器本地持久化。
- 导出包含字音标注、逐段异文（两边用字＋两边批注）、检查记录、对仗与版本来源的 Markdown 校对稿。
- 针对平板和桌面优化布局，支持长时编辑。

## 技术栈

- Angular 19（standalone components）
- TypeScript
- NG-ZORRO
- RxJS 与 Angular Signals
- Less
- 原生 `localStorage`

## 本地开发

```bash
npm install
npm start
```

浏览器打开终端提供的本地地址。

## 生产构建

```bash
npm run build
```

生产文件位于 `dist/app/browser/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `↑ / ↓ / ← / →` | 在字格中移动 |
| `1 / 2 / 3` | 标为平 / 仄 / 中 |
| `R` | 循环切换韵组 |
| `Space` | 切换停顿标记 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 本地保存提示 |

## Docker

容器内由 nginx 监听端口 `80`，源码不硬编码宿主端口。

```bash
docker build -t classical-poetry-meter-editor .
docker run --rm -p 10015:80 classical-poetry-meter-editor
```

宿主端口 `10015` 仅用于本地运行示例，实际端口由根编排文件统一管理。
